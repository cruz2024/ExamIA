# Demostración por Telegram

1. Abre Ollama y ejecuta main.py desde la terminal.
2. En Telegram usa /start.
3. Pregunta: Cómo aprender Java desde cero.
4. Pregunta: Qué es la fotosíntesis.
5. Escribe: Explícalo con un ejemplo sencillo. Demuestra contexto.
6. Usa /estado para revisar el modelo, intención y entidades.
7. Usa /ticket, describe una falla, selecciona prioridad y confirma.
8. Usa /tickets y reinicia el programa para demostrar persistencia.
9. Explica que la matriz PLN extrae metadatos y no contiene respuestas generales.
10. Explica que /ayuda y validaciones son mensajes operativos, mientras las
    respuestas normales proceden del modelo local.

No mostrar el token al compartir pantalla. No presentar pruebas simuladas como
una ejecución real de tu PC. Ensayar ambos integrantes, 10 minutos + 5 de preguntas.
El código está sin comentarios a petición del autor; la rúbrica anterior pedía
comentarios explicativos. El dominio se amplió a consultas generales y la matriz
conserva el soporte técnico. El PDF deja claras esas diferencias.
